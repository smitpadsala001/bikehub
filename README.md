# MotoVerse 🏍️

MotoVerse is a frontend motorcycle blogging website created for a Web Application Development final project.

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Design

## Features

- Home page
- Bike categories
- Bike search
- Bike filtering
- Bike details
- Wishlist
- Wallpaper gallery
- Riding destinations
- Things to do at destinations
- Blog section
- Login form validation
- Registration form validation
- Password show/hide
- Dark/light mode
- Responsive mobile navigation
- GitHub Pages ready

## How to Run

Open `index.html` in a browser.

For development, VS Code with Live Server is recommended.

## GitHub Pages

Upload the complete project to a GitHub repository and enable:

Settings → Pages → Deploy from branch → main → root

Then open the generated GitHub Pages URL.
